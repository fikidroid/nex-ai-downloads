# NEX AI Downloads

Official installers for NEX AI on Windows and macOS.

Download the latest version from the [latest release](https://github.com/fikidroid/nex-ai-downloads/releases/latest):

- Windows 10/11 (64-bit): `NEX.AI.Setup.<version>.exe`
- macOS Apple Silicon (M1 to M5): `NEX.AI-<version>-M-Series.dmg`
- macOS Intel: `NEX.AI-<version>-Intel.dmg`

Earlier versions are listed under [Releases](https://github.com/fikidroid/nex-ai-downloads/releases).
Product information and support: https://nexai-studio.vercel.app
